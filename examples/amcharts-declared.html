MAIDR + amCharts 5 Declared Traces

Five readings amCharts leaves no signature for. A survival curve and a step line are the same series class; an error bar is a floating column behind another series; a volcano, a Manhattan and a plain scatter are all a LineSeries with the stroke switched off. Every one of those configurations is worn by an ordinary chart too, so the adapter does not guess — the author says which it is, in the userData slot amCharts documents as "a storage for any custom user data": 

am5xy.StepLineSeries.new(root, {
  /* … the settings you already wrote … */
  userData: { maidr: { type: "survival", censored: "censored" } },
});

Every field is spelled exactly like the grammar field it fills, and every field naming a column of your data defaults to that same name — so a row that already carries a censored or a weight column needs nothing said about it. Nothing is ever guessed: the values that would invert a reading if guessed wrong (a significance cutoff, a forest plot's null line) have no defaults at all, and a chart that does not declare one simply makes no claim.

Survival: a Kaplan-Meier curve, censoring and all

Error bar: an estimate and the column drawing its interval

Forest: a meta-analysis, with weights and a pooled summary

Volcano: effect size against significance

Manhattan: three chromosomes read as one cloud
