MAIDR + PowerPoint and Word Task Pane (simulated file)

An Office add-in's task pane, reading the charts of the open presentation or document. Tab to the Chart picker to choose a chart, then Tab to the chart and use the arrow keys. Toggle B for Braille, T for Text, S for Sonification, and R for Review mode.

No PowerPoint or Word here. A real task pane runs inside PowerPoint or Word, which hand it the file through Office.js. This page writes a small presentation of three charts on three slides, installs a stand-in for Office.js that hands it over, and calls maidrOffice.bindOffice(element) as a task pane would from Office.onReady. Add ?host=Word to the address for a Word document of two charts instead. The buttons under The file stand for what a user does outside the pane. Build the bundles first with npm run build.
