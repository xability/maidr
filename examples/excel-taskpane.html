MAIDR + Excel Task Pane (simulated workbook)

An Excel add-in's task pane, reading the charts of the open workbook. Tab to the Chart picker to choose a chart, then Tab to the chart and use the arrow keys. Toggle B for Braille, T for Text, S for Sonification, and R for Review mode.

No Excel here. A real task pane runs inside Excel, which hands it the workbook through Office.js. This page installs a stand-in for Office.js's Excel and Office objects, holding a workbook of five charts on four worksheets, and calls maidrExcel.bindExcel(element) as a task pane would from Office.onReady. The buttons under The workbook stand for what a user does in the grid. Add ?api=1.11 to the address to see what an Excel too old to share its charts gets. Build the bundles first with npm run build.
